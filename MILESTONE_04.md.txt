Description of research topics above with points
---  
4 points  - Integrated image handling using Cheerio for scraping as well as micro link API for websites with stricter scraping blockers 

2 points - 2 Mocha tests (had a 3rd one for add item but that one was getting tricky since I'd have to update it each time I ran the test and it was hard adding that much manual info for diff clothing items into the testing file, (because once it added once it would say it failed because you can't add the same clothing item twice), but I have that version of the code too (and you can see the items from multiple iterations of running the test code on the all items page) 

4 points - Used Geocoding API (to convert zip code to latitude/longitude) and Places AI (for nearby search functionality) from Google Maps API so that users could input their zip code and find the closest store locations for brands they're interested in (some relevant documentation linked in attribution)
